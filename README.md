# オブリエ / OBRIER

**ありがとうを、綴じる。**

Slack / Teams のやり取りから感謝の言葉を LLM で自動検出し、受け取った本人の「ありがとうアルバム」に綴じる B2B サービス。

名称は obrigado（葡：ありがとう）× relier（仏：綴じる・結ぶ）の造語。ともにラテン語 *ligare*（結ぶ）を語源に持ち、「感謝」と「絆」が同じ根から生まれた言葉であることをブランドの物語とする。

デジタルハリウッド課題（作成：ゆうき）

## サービスの狙い

| | 狙い |
|---|---|
| ① | **自己肯定感** — 届いた感謝を見返せる |
| ② | **得意の発見** — 感謝の場面タグの偏りから自分のカタチが見える |
| ③ | **感謝の連鎖** — 送る側の記録も残る |

## 検査

```bash
node tools/check.mjs      # 回帰15項目
node tools/uiux-gate.mjs  # UI/UX 19項目
```

どちらも実際にブラウザで開いて操作し、**描画結果から**判定する（CSSの記述は見ない）。終了コード 0 が合格。

判定器そのものが間違っていた例がこれまでに4件ある——ダイアログの中を巡回していない／巡回の入口が隠れた表の行に当たって上司画面へ入れていない／焦点の復帰を1つの経路でしか測っていない／「開ける」を要素の**数**で判定していて裏を向いて何も描かれていない状態を通す。いずれも合格を出す側ではなく、**それを疑う側（監査人・実装者）が見つけた**。合格の数字だけを根拠にしないこと。

### プロトタイプに埋め込んだ自己診断

ヘッダー右端のビルド表示（`rev.NN`）を押すと、詳細を閉じるときのなめらかさを画面自身が測る。判定は**着地ずれ**（戻り切った最後のコマで、カードが元の位置からどれだけ離れているか。2px以下で合格）で行う。コマ落ちが1つも無くても跳ねることがあり、フレーム時間の計測では検出できないため。

## 絶対に守る設計原則

1. **アルバムの世界観（B案：紙＋タグ色）** — 白地×薄い青の方眼を台紙に、白い紙のカード（上端に場面タグ色の帯）を貼る。ゴム印風の日付スタンプ、月ごとの綴じ。感謝本文は**ゴシック体**。カードの丈は全枚そろえ、量は行数で受け止める。無機質な管理画面にしない
2. **奥行きはアバターのみ** — カード上で3Dの奥行きを持たせるのはアバターだけ。3Dチルト・光沢は使わない
3. **アバターは濃紺 #3A4A66 の1色** — 人ごとの色分けはしない。拡大詳細の文字色も同じ濃紺で統一する
4. **カードは押したら拡大詳細** — 裏面（めくり）は持たない。遷移は表にカード・裏に詳細を貼った1つの要素ごと裏返す（380ms）。お気に入りの操作は拡大詳細の中で行う
5. **非ランキング** — 個人間の順位付け表示はしない（上司テーブルのソートは許可されている）
6. **上司ビュー＝本人が見ている画面そのまま＋上司限定パネル（＋α）**。上司限定部分には「本人には表示されません」と明示
7. **じぶんのメモは本人のみ** — 上司・管理者向け API レスポンスに絶対に含めない（管理者も閲覧不可）
8. **場面タグは可変** — 固定5分類ではなく、感謝の内容から LLM が自動生成して増える
9. **削除は復元不可** — 確認ダイアログ必須
10. **通知は控えめ・言葉調** — 週1メールのみ。比較・催促表現の禁止
11. **キザな文言を使わない** — 操作フィードバックは「綴じました」ではなく「保存しました」
12. **レスポンシブ必須**（PC・スマホ）

## 実装上の重要仕様

詳細は [`docs/detailed-design.md`](docs/detailed-design.md) を参照。

- **感謝検出**：ルール前段（辞書・絵文字）→ LLM 判定（宛先／タグ／皮肉／信頼度）。信頼度 0.80 以上のみ保存。感謝でないメッセージは保存しない
- **推移チャート**：期間タブ（1週間／1か月／1年／3年／5年）、日次または月次、3年以上は横スクロール、ホバーでクロスヘア＋数値。通常時は数値ラベルなし
- **1on1準備メモ（上司向け月次）**：①今月のようす ②そのまま伝えられる称賛（引用＋事実＋伝え方例）③気にかけたいサイン ④聞いてみたい問い ⑤前回からの持ち越し
- **アラート判定**：受信または送信が前月比 50% 以上減 × 2か月連続。本人には通知しない
- **権限**：本人／直属上司／管理者。上司・管理者の閲覧は監査ログに記録
- **管理者設定（S09）**：連携設定／チーム・メンバー管理／監査ログ／検出品質モニタ
