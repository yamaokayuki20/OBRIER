# オブリエ / OBRIER

オブリエは、Slack / Teams のやり取りから感謝の言葉を LLM で自動検出し、受け取った本人の「ありがとうアルバム」に綴じる B2B サービスです。

名称は obrigado（葡：ありがとう）× relier（仏：綴じる・結ぶ）の造語で、
「アルバムに大切な写真を集めていくように、人からもらった感謝の言葉を大切にしてほしい」
という思いが込められています。

---

## サービスの狙い

| | 狙い |
|---|---|
| ① | **自己肯定感** — 届いた感謝を見返せる |
| ② | **得意の発見** — 感謝の場面タグの偏りから自分のカタチが見える |
| ③ | **感謝の連鎖** — 送る側の記録も残る |

## 絶対に守る設計原則

1. **アルバムの世界観** — 紙テクスチャ、タグ連動マスキングテープ、明朝体の感謝本文、月ごとの綴じ。無機質な管理画面にしない
2. **非ランキング** — 個人間の順位付け表示はしない（上司テーブルのソートは許可されている）
3. **上司ビュー＝本人が見ている画面そのまま＋上司限定パネル（＋α）**。上司限定部分には「本人には表示されません」と明示
4. **じぶんのメモは本人のみ** — 上司・管理者向け API レスポンスに絶対に含めない
5. **場面タグは可変** — 固定5分類ではなく、感謝の内容から LLM が自動生成して増える
6. **削除は復元不可** — 確認ダイアログ必須
7. **通知は控えめ・言葉調** — 週1メールのみ。比較・催促表現の禁止
8. **レスポンシブ必須**（PC・スマホ）

## 実装上の重要仕様

詳細は [`docs/detailed-design.md`](docs/detailed-design.md) を参照。

- **感謝検出**：ルール前段（辞書・絵文字）→ LLM 判定（宛先／タグ／皮肉／信頼度）。信頼度 0.80 以上のみ保存。感謝でないメッセージは保存しない
- **推移チャート**：期間タブ（1週間／1か月／1年／3年／5年）、日次または月次、3年以上は横スクロール、ホバーでクロスヘア＋数値。通常時は数値ラベルなし
- **1on1準備メモ（上司向け月次）**：①今月のようす ②そのまま伝えられる称賛（引用＋事実＋伝え方例）③気にかけたいサイン ④聞いてみたい問い ⑤前回からの持ち越し
- **アラート判定**：受信または送信が前月比 50% 以上減 × 2か月連続。本人には通知しない
- **権限**：本人／直属上司／管理者。上司の閲覧は監査ログに記録
